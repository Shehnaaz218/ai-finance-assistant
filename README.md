#  AI Finance Assistant

An AI-powered multi-agent financial assistant that helps users understand finance concepts, analyze portfolios, get market insights, and plan financial goals using conversational AI.

---

## Features

- 🤖 Multi-Agent System (6 specialized agents)
- 📚 Finance Q&A (RAG-based knowledge retrieval)
- 📊 Portfolio Analysis
- 📈 Real-time Stock Data (yFinance API)
- 🎯 Financial Goal Planning
- 🧾 Tax Explanation
- 📰 Financial News Summarization
- 🌐 Interactive Web UI (Streamlit)

---

##  Architecture

User Query → Router → Specialized Agent → RAG / API → LLM → Response

### Agents:
- Finance Q&A Agent
- Portfolio Analysis Agent
- Market Analysis Agent
- Goal Planning Agent
- Tax Agent
- News Agent

---

##  Tech Stack

- Python
- LangChain & LangGraph
- OpenAI GPT (LLM)
- ChromaDB (Vector Database)
- yFinance API (Real-time data)
- Streamlit (Web UI)
